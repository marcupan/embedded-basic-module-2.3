# Модуль 2.3: три світлодіоди без delay()

Домашнє завдання курсу Embedded Basic.
Плата ESP32-S3-WROOM-1-N16R8, PlatformIO, Arduino.

## Схема

```
GPIO18 -> 220 Ом -> LED1 -> GND   кожні 200 мс
GPIO17 -> 220 Ом -> LED2 -> GND   кожні 500 мс
GPIO16 -> 220 Ом -> LED3 -> GND   кожні 1000 мс
```

## Що робить

- Три світлодіоди перемикаються кожен зі своїм інтервалом, одночасно.
- Немає `delay()` і немає `while`, який чекає часу. Час береться з `millis()`.
- Раз на 10 с у Serial друкується, скільки разів перемкнувся кожен світлодіод.

## Як зроблено

- Клас `BlinkLed`: у кожного світлодіода свій пін, свій інтервал і свій час останнього перемикання `last_`.
- `update(now)` викликається на кожному оберті `loop()`. Якщо інтервал ще не минув, метод одразу виходить, тому оберт займає мікросекунди і жоден світлодіод не чекає інший.
- Перевірка `now - last_ < interval_`, а не `now >= last_ + interval_`. Беззнакове віднімання дає правильну різницю і після переповнення `millis()` (приблизно через 49,7 доби).
- `millis()` викликається один раз на оберт, і всі три світлодіоди порівнюють себе з тією самою миттю.
- Світлодіоди лежать у масиві, тож четвертий додається одним рядком.

## Запуск

```
pio run -t upload -t monitor
```

## Результат

```
10000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
20000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
30000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
40000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
50000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
60000 мс · за 10 с:  GPIO18 = 50  GPIO17 = 20  GPIO16 = 10
```

10 000 мс / 200 мс = 50, 10 000 / 500 = 20, 10 000 / 1000 = 10. Числа збігаються з розрахунком і не змінюються від вікна до вікна, тобто ритми не «пливуть» і не заважають один одному.
